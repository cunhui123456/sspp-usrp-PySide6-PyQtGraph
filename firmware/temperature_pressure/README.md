# 温压实验固件包

本目录供多传感器实验台显式“烧录并验证”使用。软件启动、刷新端口和全局初始化均不烧录。当前板卡限定为先前实测的 **Arduino Nano / ATmega328P / Old Bootloader**；上传为 57600 波特，运行数据为 9600 波特。

| 实验模式 | 已有应用 HEX | 接线与输出 |
| --- | --- | --- |
| 压力 `pressure_v1` | `pressure_v1.hex` | TCA9555 P2 / S3，A2；`millis,电压` 两列 |
| 温度 `temperature_v1` | `temperature_v1.hex` | P5 / S6、P6 / S7 共用 A1，顺序采样；两组三列时间、ADC、电压 |

源码正本仍位于既有 `arduino-sensor` 仓库；本目录是与配套 HEX 共同分发的原字节副本，SHA-256 与来源保存在 `manifest.json`。本轮没有改动这两份算法、重新编译或实际烧录。温度 HEX 为 2026-09-07 编译、烧录、校验通过的 6484 字节应用。压力 HEX 为当天完整 Flash 备份提取的 30720 字节应用区（包含原尾部内容），不是本轮重新编译的产物，亦不包含 bootloader。

准备流程先校验包文件，再检查现有 avrdude 能否启动；读取 `1e950f` 芯片签名和完整 32768 字节 Flash 备份成功后，才写入所选应用并校验。不会使用 `-F` 绕过芯片签名，也不会写入 EEPROM、熔丝或 bootloader。写入期间请求取消，将等待当前写入和校验结束；此时请勿拔线。进程异常、超时或写入校验失败，必须重新烧录并验证后才能采集。

每次准备的备份、应用镜像、工具日志、串口验证字节及来源哈希保存于 `Data/device_preparations/<时间>/`，与正式实验记录分开。**完整 `flash_before.bin` 包含 bootloader，不应直接作为普通应用烧录文件**；恢复操作须先按原板卡应用边界提取并核验，不自动回写。

烧录后仍须接收到至少三个完整、连续且 MCU 时间递增的数据帧才会就绪。验证已有固件只证明输出协议；不读取程序身份，也不把本目录 HEX 哈希写成板上当前固件哈希。协议通过不意味着电压已换算为真实温度／压力，也不能替代传感器标定。
