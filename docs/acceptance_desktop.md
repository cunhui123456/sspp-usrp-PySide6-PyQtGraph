- 每帧保留原始整秒 / 小数秒、主时钟 tick、预期位置和偏差。旧 `device_tick_at_rx_rate` 含义不变，作为兼容证据，不再用于新连续性判据。
- 拒绝帧单独保存 `rx_timestamp_failure.json`，不加入有效 IQ；manifest 记录判据与失败证据入口。
- 停止原因记录首个实际触发事件，区分时间戳错误、其他 RX/TX 错误、watchdog、初始化、处理异常和主动停止。
- 实时状态即时展示 COMPLETE 错误；历史详情保留脱敏错误。诊断图优先用主时钟证据，旧取整时间戳的 ±1 差值明确提示可能来自舍入。
