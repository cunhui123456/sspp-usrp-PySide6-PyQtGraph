## 2026-10-10 确认的两类实验

### 材料扫频

以材料／条件命名一次记录，固定样品后自动逐频点测量，呈现频率—幅度、各轮结果及重复性。换材料或状态后另起记录。频点数 × 重复轮数表示技术测量次数，不能视为独立取放次数或材料分类样本量。保留老师测量逻辑和既有参数边界，不声称自动分类或标定 S21。

### 固定频率手指实验

同时支持引导式尺子测量和自由探索。引导流程在同一次连续采集中建立参考、采集多个尺量距离的稳定段、独立验证，然后观察估算；自由流程记录幅相与人工动作，再从保存序列选择静止区间、输入当时尺子真值进行相同分析。

必须同时报告传感器到手指的**距离**与相对初始尺量距离的**位移**；位移正值表示远离。尺子真值由操作者测量和输入，不自动检测位置，不以波长公式代替标定。

仅用标定区间构建相位—距离单调经验曲线，独立留出区间评估误差。至少 3 个不同标定距离、2 个不同验证距离，所有选段不重叠，标定与验证至少间隔 1 秒。不得把同一连续静止段切开伪作独立验证。门槛和来源随报告保存；默认允许误差 2 mm 是策略，未经真实实验不能宣称达到该精度。

只有同一 run、相同相位参考、质量合格、曲线单调且独立验证通过时才激活毫米估算；不外推，不盲目复用其他 run 的模型。非单调、迟滞／漂移、质量不足、范围外或无效来源需明确拒绝并保留原因。

离线选段只读取保存序列，手动标注不能改写原始数据。没有当时尺量真值的旧静态记录可用于观察和软件检查，不能补造为真实毫米验证数据。报告需包含标定／验证区间、真值、预测、误差、来源哈希及适用范围。
