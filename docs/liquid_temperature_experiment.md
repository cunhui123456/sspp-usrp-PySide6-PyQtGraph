# 液体温度对扫频与位移相位响应的影响实验

本实验增加到现有 PySide6 + PyQtGraph 桌面程序的“液体温度影响”工作区，继续使用 `rf-gnuradio` 环境及根目录 `run_desktop.command`。它复用既有逐点扫频和固定载频连续幅相采集，补充结构化液体条件、参考温度、距离、温度平台、稳定区间及版本化分析报告。

本次交付范围为软件实现、合成数据测试和离线验证；没有执行新的 USRP 探测、初始化或射频收发，没有获得真实液体温度效应或位移精度结论。实际采集仍由操作者检查本次设备、接线、参数及现场条件后启动。

## 1. 温度为什么可能改变曲线

液体的复介电常数可写作 `ε*(f,T) = ε′(f,T) − jε″(f,T)`。温度会影响介电极化与损耗，因此液体加载下的传输幅度、相位和某些曲线特征可能随温度变化。水在微波频率下的介电性质具有频率和温度依赖，参见原始研究 [Water: a dielectric reference](https://www.sciencedirect.com/science/article/pii/0167732296009269)。这是开展实验的物理依据，不能直接视为当前 SSPP 样品已经验证的温度响应。

对本装置，需分别检验：

| 研究问题 | 控制方式 | 主要结果 |
|---|---|---|
| 同一位置的扫频幅度是否随液体温度变化？ | 固定容器、体积、位置、姿态与线缆，只改变温度 | 曲线叠加、同频点幅度差、描述性 dB/℃ 系数 |
| 同一位置的相位是否随温度或时间漂移？ | 同一次连续采集中固定距离，记录多个温度平台的 reference | 同距离相位差、参考温差及两窗口时间间隔 |
| 温度是否改变位移引起的相位响应？ | 各稳定温度下重复相同参考位置和位移位置 | 各温度平台内相位—位移曲线与斜率 `°/mm` |

真实曲线能否区分，还取决于温度跨度、传感器敏感区域、信号噪声、接触几何与装置漂移。当前不能预设升温一定导致向高频或低频移动，也不能保证某个峰谷始终存在。液体、容器、FPC、夹具和线缆同时受热时，仅凭 RF 曲线不能把各因素分离。

本实验记录的扫频纵轴是数字 FFT 单音幅度估计，**不是经过端口校准的 S21 或 dBm**。它没有自动测量或反演介电常数，也不把峰谷移动换算为介电常数。

## 2. 先固定实验条件

建议先用同一份水做小范围试验，例如把 **20、30、40 ℃** 作为可调整的目标温度计划。这些数值不是强制配置、实测范围或已验证最佳温度；应按样品和实际温控能力调整。实际参考温度必须来自独立温度计，不能使用加热器设定值替代。

开始前确定并记录：

- **液体与样品**：名称、成分或浓度、样品编号、液体体积。全组使用相同装液量，观察是否出现蒸发、残液或液面变化。
- **容器**：固定容器编号、材质和尺寸。更换容器或改变填充量应另列条件。
- **机械几何**：明确传感器到容器哪一表面的距离、运动轴及正方向，固定姿态、夹持或接触条件、线缆和接头。远离为正位移。
- **参考温度**：温度计型号或编号、探头位置、读数方法。温度读数属于参考仪表示值；本软件不替温度计做校准。
- **重复编号**：独立重新放置或重新夹持的测量使用不同 `repeat_id`；同一 run 的多轮扫频只是技术重复，不能算多次独立实验。
- **RF 设置**：同一比较组保持设备配置、采样率、TX/RX 增益、数字幅值、采集窗、载频或频率网格等设置一致。

每个平台等待液体读数趋稳后再采样，并记录开始和结束参考温度。默认 **0.5 ℃** 是软件筛选首尾温差和平台温差的分析门槛，**不是温度计精度或液体全程恒温证明**。应在观察结果之前按实验需要确定容差。首尾相同仍可能遗漏中途波动或空间温度梯度。

为区分温度、时间与机械变化，建议采用升温后降温回测，例如 20 → 30 → 40 → 30 → 20 ℃，并在多次独立实验中改变顺序或重新建立相同条件。恒温但持续等待的记录有助于估计时间漂移；空容器或其他明确设计的对照有助于检查容器、夹具和环境影响。对照不自动证明单一因果，需要结合实际温控和几何记录判断。

## 3. 固定位置的温度扫频

1. 用 `run_desktop.command` 打开软件，进入“液体温度影响”页的“① 实验条件”。
2. 选择“固定位置 · 温度扫频”，填写液体、样品、容器、体积、几何条件、温度计、目标温度、开始参考温度、开始参考距离和独立重复编号。
3. 点“应用条件到采集参数”，回到采集区检查设备和扫频参数，并确认本次接线与现场条件。应用条件不会自动发射或开始采集。
4. 完成一次扫频期间保持样品位置与温度条件。需要改变位置、材料、液量或其他主要条件时，另起记录。
5. 扫频结束后记录真实结束温度，等待采集保存及停止证据完成。在“② 记录与稳定区间”刷新记录，选中并“载入选中记录”，填写结束参考温度，点“保存标注 / 结束温度”。
6. 对各温度重复上述流程。勾选 2–8 条同类已完成记录，点“比较勾选的同类记录”。**列表中的第一条勾选记录作为参考**，报告会记录参考 key；差值定义为目标减参考。若需更改参考，先核对列表顺序及报告标识。
7. 到“③ 分析报告”查看曲线和质量明细，再按需打包导出。

比较会检查已保存的采集设置和共同实际 TX/RX 载波回读与单音组合。它不按频点序号盲配对、不插值、不补偿不同增益。不同温度记录的液体、样品、容器、体积、几何、距离或温度计不一致，或缺少结束温度、首尾温差超限时，只保留可用叠加和问题说明，不输出可被误读为温度定量结论的差值。

条件通过时，逐点数字幅度差为：

```text
ΔA(f) = A目标(f) − A参考(f)
ΔT = (T目标开始 + T目标结束)/2 − (T参考开始 + T参考结束)/2
描述性温度系数 = ΔA(f) / ΔT
```

这里的温度均值只是首尾读数平均，不是全程时间平均；仅在不同温度配对有效且 `|ΔT|` 超过所选容差时生成 dB/℃。该系数依赖当前频段、样品和几何条件，不是材料本征常数。扫频误差棒为轮间样本标准差，不是均值差置信区间，也不表示独立取放重复性。

## 4. 各温度下的位移相位响应

实际达到热平衡通常需要比单次连续记录更长的时间。默认做法是：**先在一个温度平台稳定，再为该温度单独启动一次固定载频相位记录**；完成后在下一温度重新建立参考。软件保留既有单次相位 10–180 秒范围，不自动延长采集时间，不拼接不同 run 的相位。

### 4.1 现场记录

1. 在“① 实验条件”选择“固定载频 · 温度与位移相位”，记录当前条件并应用到采集参数。
2. 保持各温度相位实验的载频、基带单音及其余 RF 设置一致。载频应按现有装置可用信号与预实验确定，不能把本次温度分析当作自动选频。
3. 在实际参考距离静止，启动采集并等待初始基线通过。默认采集仍约有 2 秒等待和 5 秒基线建立，后续稳定区间必须位于基线结束之后。
4. 依次测量 reference 初始位置、至少两个不同 displacement 位置、回到初始 reference 位置。每次移动后等待稳定，再记录稳定段的起止时间、实际距离和首尾参考温度。可以在同一温度重复往返，使用新的平台/周期编号。
5. 总时长需容纳基线、全部移动、等待和稳定窗口。不能为了凑满计划把移动段算成稳定段；时间不足时结束后另起 run，并为新 run 重新建立参考。
6. 停止并等待保存和完整停止证据，再进行离线选段。所有温度与距离必须来自现场实际记录，禁止依据曲线形状回填猜测温度或距离。

本程序不控制丝杠、加热器或参考温度计，不自动检测定位是否准确。可结合既有实时标记与回放核对时段；按钮时刻不等于物理运动已完成，最终分析使用所选 `[开始, 结束)` 内的真实保存记录。

### 4.2 在软件中标注稳定区间

1. 在“② 记录与稳定区间”载入目标相位记录。
2. 为每段填写开始秒数、结束秒数、开始参考温度、结束参考温度、实际参考距离和温度平台/周期编号。
3. 同一温度、同一次往返过程使用相同平台编号，例如 `T20_R1`。初始位置和同位置回位选“参考位置（含回位）”；其他位置选“位移位置”。平台内最早的有效窗口必须是 reference。
4. 勾选“温度与距离来自当时实际记录”，添加区间。区间不得重叠，必须避开过渡、缺口及基线建立阶段。
5. 点“保存标注 / 结束温度”保存一个新版本，再点“分析同次记录的温度与位移相位”。修改或删除标注不会改动原始 IQ、原始幅相序列或既有派生版本。
6. 其他温度各自完成采集、记录和保存后，勾选 2–8 条相位记录并比较。跨 run 比较读取各自已保存的标注，因此修改后应先保存再比较。

每个温度平台至少需要 **3 个不同位置，包含一个 reference 和两个 displacement**。末尾回位仍为同一距离，不计作第三个不同位置。选择更多位置和往返重复可帮助发现非线性、迟滞和漂移；不能通过增加同一静止段的切片数假装获得独立重复。

### 4.3 如何理解相位结果

每个平台以其最早有效 reference 的距离和相位为零点：

```text
Δx = x窗口 − xreference          （mm，远离为正）
Δφ = φ窗口 − φreference          （°）
Δφ ≈ 截距 + k × Δx             （平台内带截距最小二乘）
k = sensitivity_deg_per_mm       （°/mm）
```

拟合输入是各稳定窗口的相位中位数。报告保留窗口质量、每个平台的斜率、截距、拟合 RMSE、R²、参考温度首尾范围以及回位相位残差。回位 reference 用于检查回零漂移，不重复加权零位进入斜率拟合。回位明显偏离提示时间漂移、迟滞或重新定位误差，应结合往返顺序与独立重复解释。

- **斜率变化**回答不同温度下相同位移是否产生不同相位响应。它是当前局部几何范围内的描述性灵敏度，不自动表示全范围线性。
- **拟合 RMSE**单位是度，描述这些窗口与直线的偏离；它不是独立验证误差，更不是毫米精度。高 R² 也不能证明温度补偿或解耦成功。
- **跨 run 比较**只叠加各自 reference 归零后的曲线和平台斜率。程序不相减不同 run 的绝对相位，不比较相位截距，不把一个 run 的毫米模型用于另一个 run。
- 只有采集设置、样品条件、参考位置及采样位置集合一致时，才能开展受这些条件限制的斜率定量比较。否则报告保留曲线与不一致说明。
- 相位响应不按自由空间波长直接换算位移；当前实验不建立或启用新的毫米反演模型。需要毫米测量精度时，必须另外设计独立参考与留出验证。

## 5. 同一连续 run 的固定位置温漂

若现场能在单次时限内保留连续相位参考，并完成多个可记录的温度平台，可在同一 run 中给各平台设置不同编号。各平台都记录同一实际距离的 reference，程序可计算相对最早同距离 reference 的：

- 参考温度差 `temperature_difference_c`；
- 相位差 `phase_difference_deg`；
- 时间间隔 `elapsed_s`。

只有 reference 距离相同时才生成对应表，不用不同位置凑出温漂。只采 reference 也可保留固定位置相位漂移结果，但因缺少三个位置，平台斜率不可用，报告会说明这一限制。

**温度变化与时间先后在此设计中可能完全相关。**因此这里的相位差表示“温度与时间共同变化时的固定位置响应”，不能自动称为纯温度相位系数。应增加恒温等待、升降温回测、重复顺序或独立参考通道等证据。跨 run 无法保持同一相位参考时，只做各 run 内的相对位移响应和斜率比较，不拼接相位零点。

## 6. 质量检查与状态

| 检查 | 当前行为 |
|---|---|
| 原记录状态 | 完成、无错误，且 TX EOB、RX stop、workers 停止证据齐全后才分析 |
| 基线 | 需要有效的结束时间、相干及幅相稳定指标，并通过既有基线门槛 |
| 数据连续性 | 时间严格递增；完整相位序列的时间缺口、样本缺口、重复或重叠拒绝沿用相位参考 |
| 选段 | 基线之后，至少 0.5 秒、至少 5 条记录，首尾覆盖完整，无 transition 过渡数据 |
| 稳定窗口 | 相干占比至少 0.8，相位 SD 不超过 3°，相位漂移不超过 1°/s，幅度 SD 不超过 0.5 dB |
| 参考温度 | 需要实际首尾读数；窗口首尾温差及同平台有效窗口温度范围不超过所选容差 |
| 距离与平台 | 距离有限且非负，平台明确，reference 为最早窗口且回位 reference 距离一致 |
| 拟合设计 | 至少三个不同位置；无跨 run 绝对相位差，无范围外位移估算 |

这些门槛是软件质量策略，不是研究性能承诺。`ready` 表示所选分析满足相应软件检查；`partial` 表示部分窗口、平台或比较条件有效；`rejected` 表示不能得到有效目标分析。必须同时阅读错误和警告，不能把报告生成成功当作实验成功。

## 7. 文件、溯源与导出

原始扫频与相位记录继续位于 `Data/runs/<run>/` 和 `Data/phase_runs/<run>/`。新增实验条件写入该次记录的 `desktop_context.json`，实验类型分别为 `liquid_temperature_sweep` 和 `liquid_temperature_phase`。旧记录没有当时参考温度，不自动转换成温度实验。

人工区间及扫频结束温度按版本保存：

```text
Data/<runs 或 phase_runs>/<run>/liquid_temperature_annotations/<时间_唯一后缀>.json
```

每次分析创建独立目录：

```text
Data/liquid_temperature_reports/<时间_唯一后缀>/
  analysis.json                  完整结果、条件、问题、来源与算法哈希
  <各结果表>.csv                 窗口、平台、温漂或扫频比较表
  README.txt                     解释边界与本次问题
  comparison_report.pdf          有可绘制结果时生成
  comparison_*.png               各分析图
  report_manifest.json           报告文件大小与 SHA-256
```

相位报告的主要表为 `windows`、`blocks` 和适用时的 `thermal_drift`；扫频报告另有 `temperature_conditions` 和 `temperature_coefficients`。不同类型或不满足条件的分析不强行生成同一套数值表。

在“③ 分析报告”点击“打包导出报告…”并选择 ZIP 保存位置。报告包包含结果、条件、图表和来源索引，**不包含原始 IQ**；需要原始采集文件时使用既有单实验导出流程。打包时重新核验已记录的源文件和报告哈希，来源发生变化会拒绝沿用旧报告。查看、分析和导出都不会启动射频。

## 8. 实验完成后应保留的结论边界

一组有用的初步结果应能回答：固定几何下曲线差异是否超过重复波动；升降温回测是否恢复；各温度的相位—位移斜率是否随独立重复保持；回位残差与恒温时间漂移有多大；哪些样品、参数和温度范围实际测过。

若尚无真实数据，应记录“实验流程已建立，真实温度响应待测”。若差异接近噪声或回测不恢复，应保留不确定性并检查热稳定、机械漂移和样品条件，不把未观察到显著变化写成液体介电性质与温度无关，也不把任意曲线差异归因为温度。
