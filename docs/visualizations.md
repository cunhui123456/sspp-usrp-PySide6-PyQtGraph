# SSPP 图形说明与判读

浏览器的“实验图像与诊断”按任务分组，避免把所有曲线挤在同一屏。完整扫频12张，带有效参考/硬件帧记录的连续幅相24张；资料不完整时只展示有依据的图。原有主幅度/相位曲线继续保留。图卡注明来源、单位和解释限制，支持放大与指针读数。

## 接收诊断：两种实验共用5张

| 图 | 数据与计算 | 用途与限制 |
| --- | --- | --- |
| RX接收时域 I/Q | 实测complex64的实部/虚部，展示最近短窗，横轴ms | 观察波形与幅度；两条线来自同一个RX通道 |
| RX全带宽幅度频谱 | 最新最多8192样点，Hann窗，FFT幅度除以窗和，20log10 | 看主峰、杂散及设定单音线；横轴为相对载频的kHz，不是射频绝对频率 |
| RX原始IQ复平面 | 真实样点，最多800点；两轴相同比例 | 观察圆/椭圆和偏置；不是锁相后的复系数 |
| TX基带设定：数学参考 | `amp × exp(j2π × tone × t)`，局部相位起点为0 | 解释发射设定；没有实际TX采样，不能计算实测TX/RX插损 |
| RX抽样时频图 | 最多64个均匀抽取的真实短窗，每窗最多2048点，按频率带平均PSD | 看记录中的频谱变化；相邻时间列可能隔开，未补样，单位dBFS/Hz估计 |

连续记录的时域/频谱/IQ图来自最新完整IQ尾窗；时频图覆盖整个已保存记录的抽样窗口。扫频的这5张图仅取最新已保存NPZ，不把不同载频的IQ拼成一段连续信号。运行时可能滞后一频点，来源说明会显示NPZ文件名。

FFT频率栅格为 `rx_rate / N`。全带宽峰值不等于原扫频算法限定搜索区间的测量峰，两个读数的窗长、频率分辨率可能不同。PSD采用 `|FFT(x·w)|² / (rx_rate · Σw²)`；单位是数字量估计，尚未标定为dBm/Hz。

## 扫频分析：6张

| 图 | 用途 |
| --- | --- |
| 扫频均值与±1样本SD | 每载频将各轮dB幅度求均值及样本SD；单轮时SD空缺 |
| 各轮相对同频点均值的偏差 | 找出某一轮异常及频率相关波动 |
| 逐频点重复标准差 | 观察技术重复的稳定性 |
| 轮次×载频响应热图 | 查看所有正式测量格；缺失格不填零 |
| 设定与实测单音跟踪 | 确认正式测量峰是否随基带设定变化 |
| 正式测量单音频差 | 显示实测−设定的Hz差及原算法±200Hz验证门槛 |

同次扫频的多轮测量是技术重复，不能当作独立取放重复。误差棒不是置信区间，均值在dB域计算。扫频幅度是数字FFT幅度，不是标定S21。

## 连续幅相分析：11张

| 图 | 用途 |
| --- | --- |
| 接收单音绝对数字幅度 | 保留启动、参考及后续阶段，查看完整记录的数字幅值 |
| 相对静止参考的幅度变化 | 按同次参考归一化，保留动作过渡变化 |
| 折返与连续解缠相位 | 对照±180°折返相位与连续解缠曲线 |
| 相对参考的锁相复系数 | 复系数除以参考幅值、旋转参考相位，参考点为(1,0)；按稳定阶段着色 |
| 幅度−相位响应轨迹 | 观察阶段的联合幅相变化；不是实际手指位置轨迹 |
| 各阶段幅度均值±1样本SD | 排除参考前与过渡窗口后的阶段幅度统计 |
| 各阶段相位均值±1样本SD | 同上，相位使用连续解缠值 |
| 稳定阶段幅度分布 | 合并稳定阶段的窗口分布，观察范围及形状 |
| 稳定阶段相位分布 | 同上，相位分布 |
| 1秒滚动幅度波动 | 按实际时间求前约1秒窗口SD，保留漂移及动作 |
| 1秒滚动相位波动 | 同上，相位波动 |

阶段统计纳入参考结束后的有效稳定窗口，排除标签以`transition`开头的操作等待。连续窗口有时间相关性，窗口数量不等于独立实验次数，SD不代表动作重复性或置信区间。幅度归一化为 `A_dBFS − 20log10(A_ref)`，相位减去本次参考的解缠相位。未进行仪器漂移扣除，也未换算为毫米位移。

## 采集质量：扫频1张、幅相8张及数字指标

| 图 | 用途 |
| --- | --- |
| 每轮正式测量点数（扫频） | 正式CSV点数，与预设数量、状态及IQ文件一起检查完整性 |
| 操作阶段时间线（幅相） | 阶段起止时间；过渡为灰色；已有网页接触报告单独显示 |
| 单音相干占比估计 | 观察单音相干占比与0.5工程门槛；不是严格SNR |
| 逐窗相位增量 | 对照±120°/窗停止门槛；解缠不能唯一恢复超过180°的真实窗间变化 |
| 各阶段纳入统计的窗口数 | 说明阶段统计的数据量 |
| 静止参考幅度细节 | 查看建立参考时的幅度稳定性 |
| 静止参考相位与漂移拟合 | 查看参考相位及仅作描述的线性拟合，不用于扣除漂移 |
| RX逐帧有效样本数 | 观察帧长变化；变化本身不等于丢样 |
| 硬件时间戳连续性 | 当前帧tick减去上一帧tick+样本数；0为连续，正数间隙，负数重叠 |

“采集计数与停止证据”还显示manifest中已有的TX/RX样本、帧数、部分发送、timeout、错误数、TX EOB、RX停止命令和线程退出证据，以及IQ预览窗口RMS与近满幅分量数。没有记录的证据显示未确认，不从画面正常推断硬件正常。

操作时间线记录指令/阶段就绪时间，没有测量实际手指运动或材料接触瞬间。历史CLI记录没有网页接触报告时不补写接触状态。扫频分点保存没有全会话硬件时间戳，不能用它证明整场连续无丢样。

## 使用与导出

1. 选择“实验记录”中的真实历史记录，或在新实验进行时查看诊断。
2. 切换分组；点击图卡“放大”。图例、来源和读数会显示在大图旁。
3. “下载当前视图PNG”保存网页画布；适合快速截图，完整说明见图卡。
4. 停止采集后点击“生成PNG与PDF图册”。所有分组均导出，不只导出当前分组。每张PNG含标题、单位、图例、实验编号及来源说明，多页PDF每页一张。
5. 可展开PNG缩略图册，或在实验文件列表中打开/下载。PNG约1870×1139，PDF保留可缩放的坐标和曲线。

新增文件留在同一实验目录：

```text
diagnostic_01_rx_wave.png ...
diagnostic_report.pdf
diagnostic_figures.json
```

索引保存生成时间、图题/分组/说明、绘图源码SHA256及输入manifest SHA256。原始IQ、正式CSV、事件、参考和历史manifest不改写。再次生成会原子替换同名派生图；结束的实验图会按输入文件变动刷新缓存。图册由独立进程导出，期间阻止启动新采集，60秒超时会终止导出进程。

## 判读顺序

先看运行状态和采集指标，再看RX频谱的主峰是否跟随设定单音、时域及IQ是否合理，最后比较扫频重复性或动作阶段幅相变化。单次收到信号不足以排除泄漏/串扰路径，也不足以确认传感器全部工作机理；传播路径需要后续断路、直连、参考状态等对照实验。

这次图形升级使用已有真实记录验证，没有启动新的RF收发。绘图模块不导入UHD、不初始化B210；合成测试数据仅用于数值回归，不作为真实实验验收。
