# 多传感器实验台工作流

## 开始前：分别初始化射频与 Arduino 设备

1. 打开“多传感器实验台”，默认进入材料扫频；启动不会连接设备。
2. 点击“初始化实验台”，在弹窗选择全局 B210 和 Arduino USB 串口，勾选本次需要检查的设备；取消弹窗保持原设置。端口列表仅列支持的 USB 串口候选，排除蓝牙和系统虚拟端口；刷新不打开设备。
3. 确认后后台分别检查串口和 USRP；终端实时显示过程，每10秒显示等待进度。串口最多30秒，USRP最多120秒。“取消初始化”只中止未完成部分，保留已经成功的设备。
4. 顶部分别显示两类设备状态。只连接 Arduino 时可准备温压固件并采集，只连接 USRP 时可直接做射频实验；缺少的一方显示未就绪并禁用对应开始按钮，不阻止另一方。两者都未就绪时仍可看历史、分析和编辑参数。
5. 检查当前实验所需设备已就绪，核对参数并勾选接线确认，再开始采集。液体实验还需先应用温度条件。

全局 B210 选择不随实验草稿或参数复位改变。Arduino 弹窗端口同步到温压侧栏，实验模式在侧栏选择；改变设备配置只撤销该设备就绪，温压模式变化只撤销固件验证，切换实验保留两类就绪。未勾选本次检查的设备不自动打开，配置不变的既有就绪状态保留。重启软件从未初始化开始。

检查结束释放设备，实际采集使用原有采集流程。沿用已验证的 Arduino 压力／双通道温度协议，串口打开可能复位 Nano；全局初始化不烧录，也不把连接成功当作固件已验证或传感器标定。温压页必须通过显式“烧录并验证”或“验证已有固件”完成数据检查，详见[温压固件准备与采集](temperature_firmware_workflow.md)。日志保存在 `.cache/initialization_logs/`，两类设备的路径分别见状态悬浮提示；终端保留异常、取消和超时原因。实验 `Data` 不写入初始化日志。

## 1. 先选择研究问题

窗口顶部全宽导航为“材料扫频”“手指位移”“液体温度影响”“温压采集”。左侧随选择显示专属参数，右侧提供对应的实时、档案、诊断或研究分析内容；手指的实际定位确认、动作记录、区间和报告仍在右侧，尺量参考、窗口时长、操作方式与引导距离计划在左侧。

各实验草稿在当前窗口内分别保留，切换后恢复相应参数；切换时清除接线确认及旧的档案勾选，避免把上一实验的确认带入下一实验。温压使用自己的串口协议和接线确认。参数草稿不会因此写入 `.env`，切换也不会打开硬件。

初始化、采集、参数检查、停止保存和相关结果处理期间，顶部实验导航不可切换。顶端“停止并保存”固定可见，采集中在任何右侧工作页都可操作；无活动采集时禁用。点停止后须等待保存及停止证据，不能马上拔除设备或把按钮点击记为已停止。

顶部“全部实验档案”用于跨类型访问已有 RF 记录，取消“仅当前实验”范围筛选；普通档案页默认只展示当前实验类型。温压历史仍从“研究分析与模型”的数据源列表进入，本轮只重组界面，没有把串口历史并入 RF 档案后端。

| 问题 | 选择 | 本次能得到什么 |
|---|---|---|
| 某材料在不同频率下的幅度响应如何？ | 材料扫频 | 各频点／各轮幅度、均值与标准差、频点 IQ 和诊断图 |
| 手指位置与同次相位变化有没有可验证的单调关系？ | 固定频率手指 · 引导采点 | 预设尺量位置、稳定窗口、独立验证误差和同次范围内毫米估算 |
| 想先探索动作，再从记录中选择稳定段分析？ | 固定频率手指 · 自由记录 | 幅相、人工动作、尺量说明和离线区间分析；无真值时只做信号观察 |
| 液体温度是否改变扫频及位移相位响应？ | 液体温度影响 | 温度扫频比较、平台内相位—位移斜率、同 run 固定位置漂移；实际温度需参考仪表记录 |
| 如何保存 Arduino 温压读数并做后续标定？ | 温压采集 | 串口原始字节、ADC／名义电压、时间和事件；参考温度／载荷另行记录和标定 |

一次运行只服务一个当前实验。材料名称、动作按钮和尺量输入都是操作者记录；程序不自动识别材料、动作或位置，也不控制机械移动。

### 参数复位

左侧 RF 操作区的“当前实验参数复位”恢复**当前实验草稿中的全部采集数值参数及高级参数**，包含该草稿内隐藏采集模式的数值字段；其他实验已保存的草稿保持不变。默认值与软件初始参数使用同一来源：

- 材料扫频：2.4–3.0 GHz、12 点、3 轮、总时限 90 秒、单点时限 8 秒、首个单音 2000 Hz、单音步进 1000 Hz。
- 固定频率手指：载频 2.4 GHz、记录 120 秒、基带单音 10000 Hz。
- 共用高级参数：采样率 250000 S/s、数字幅值 0.3、TX 增益 20 dB、RX 增益 30 dB。

当前实验类型、设备选择、材料名称、会话标签和传感器说明保持；手指标定页的尺量设置、标注、模型以及历史实验也保持。复位后接线确认取消勾选，检查参数和现场条件后再确认。本操作只修改待采集表单，不调用硬件、不开始新实验，也不写入 `.env`。初始化、采集、停止保存、参数检查及窗口关闭期间不可复位。

## 2. 材料扫频：一次记录对应一个材料／条件

1. 在顶部选择“材料扫频”，在左侧填写“材料／条件名称”，例如空瓶或某材料状态。记录传感器与摆放条件，固定样品和线缆。
2. 核对顶部显示的全局设备，必要时在初始化弹窗切换并重新检查；设置起止载频、频点数、重复轮数和其余采集参数。先检查参数，再确认现场条件。
3. 点“开始材料扫频”。每个频点先验证信号再测量，完成一点后增加一条结果；RX 诊断展示当前真实接收窗口。
4. 全程保持本次材料与摆放条件不变。更换材料、填充量、姿态或位置时，结束本次并另起记录，以免一个标签混入多个条件。
5. 结束后检查错误与停止证据，再查看结果、逐点 IQ、CSV、Excel 和图册。需要分享时打包导出。

**频点数 × 重复轮数是技术测量次数。**例如 12 点 × 3 轮得到 36 次点测量，不表示做了 36 次独立取放，也不是 36 类动作。各轮标准差主要描述固定配置内的重复性；要研究重新摆放或不同样品的变化，应另做有记录的独立实验。

结果的数字幅值不是校准 dBm 或 S21；本版本不自动分类材料。可对同类型完成记录叠加浏览，并在参数可比、共同测量频点存在时计算目标减参考的幅度差，见 [结果比较](results_comparison.md)。标签和完整条件记录仍是解释差异的基础。

## 3. 手指实验的距离定义

先固定可复现的几何基准：说明传感器哪一表面到手指哪一位置、测量方向、尺子放法、手指姿态和线缆状态。全过程使用同一定义。

- **尺量距离 `distance_mm`**：操作者实测传感器到手指的几何距离。
- **初始尺量距离**：建立本次静止参考时的手指距离；它定义位移零点。
- **位移 `displacement_mm`**：估计距离减初始尺量距离；远离为正，靠近为负。
- **相位参考**：本次连续采集初始静止段的参考，不是跨会话通用零相位。

毫米映射只使用**同一 run 的相对解缠相位与尺量距离**构建单调分段线性曲线。它是局部经验模型，不使用传播波长直接换算手指距离。幅度用于质量检查，当前并非幅度与相位的多变量拟合。

开始固定频率采集后，前约 2 秒等待、约 5 秒建立静止参考。按初始距离保持稳定；参考通过前相对幅相和毫米值不可用，原始 RX 仍可观察。参考不通过时先查看原因，不能靠补填距离使模型有效。

## 4. 引导采点：先标定，再独立验证

在顶部选择“手指位移”，检查左侧固定载频及尺量参数，开始采集后点“进入手指标定与验证 →”。在手指研究工作区依次使用“① 现场采点”“② 区间与标注”“③ 标定与验证报告”。顶部持续显示记录来源、距离／位移和不可用原因。

1. 在左侧“尺量参考与窗口”输入初始尺量距离、验证允许误差、移动后等待和稳定采样时长。默认误差门槛 2 mm；应在看验证结果前按研究需要确定，不反复调高以制造“通过”。
2. 在左侧选择“引导采点 · 按计划逐个确认”，编辑标定距离与独立验证距离。至少 3 个不同标定位置、2 个不同验证位置，验证位置在标定距离范围内。界面 `10, 20, 30` 与 `15, 25` 只是可编辑示例。
3. 在右侧“① 现场采点”点“采用计划 / 从第一个位置开始”。软件提示下一位置，由你移动手指并用尺确认；完成定位后点“已用尺定位，开始稳定窗口”。
4. 软件等待采集进程确认标记，再按硬件样本时间计入等待段和稳定窗口。等待及采样期间保持姿态和线缆不变；窗口完成后才进入下一位置。点击时刻不等于物理动作自动同步。
5. 依次完成标定和独立验证。验证应重新定位到指定位置，不能截取某个标定静止段的另一半充当独立样本。标定与验证窗口不重叠，二者至少相隔 1 秒，并有阶段变化或明确动作证据。
6. 在“区间与标注”核对已完成窗口。只有完整稳定窗口进入分析；取消或采集提前结束的未完成窗口不用于标定，原始采集记录仍保留。
7. 到报告页点“分析标定与独立验证 / 保存结果”。分析和绘图在后台运行。通过后可在当前连续采集剩余时间内观察有效范围的毫米估算；未通过会显示原因，不填入猜测值。
8. 完成观察后停止收发，等待保存和停止证据，再检查报告与导出。

一次 phase 采集时长当前为 10–180 秒，应预留基线、移动、等待、全部窗口与后续观察时间。每个稳定窗口至少 0.5 秒，默认 2 秒；剩余时间不足时软件拒绝新窗口。开启新 run 必须重新标定与验证，不能续用旧模型。

“取消当前窗口”只取消该窗口用途，**不是停止收发**。需要结束实验时使用主界面的停止按钮。

## 5. 自由记录与保存后的区间选择

自由记录使用同一条连续幅相采集，不切换到另一种算法。

1. 在左侧选择“自由记录 · 自选位置与动作”，右侧现场采点页显示自由动作和窗口操作。移动时可记录靠近、远离、保持和说明；“记录此刻动作与尺量距离”只写操作事件，**不会自动成为标定样本**。
2. 已定位并有尺量真值时，可选择标定或独立验证，再采稳定窗口；模型通过后可选择“观察窗口（不参与拟合）”继续观察。也可以先完成连续记录、停止保存后再标注。
3. “实验档案与回放”页选择该 phase 记录，点“手指记录：标注区间 / 标定验证”。确认顶部显示目标记录；历史研究不会套用到当前采集。若已分析，会载入已有标注与报告作为起点。
4. 在“② 区间与标注”拖动相位图阴影，或输入起止秒数。选段为 `[起点, 终点)`，只选稳定位置段，排除移动过渡、基线建立和缺口。
5. 为每段输入**当时实际记录的尺量距离**、用途（标定、独立验证或观察）和动作，然后添加区间；观察段不参与拟合或验证门槛判定。可以替换或删除标注；修改尚未保存时界面会提示。图形可能经过显示抽样，数值分析读取保存的完整幅相序列。
6. 到报告页分析并保存。软件重新检查全体区间、独立性与误差，创建新的派生版本；原始 IQ、幅相序列、事件和 manifest 不被修改。

没有当时尺子读数的记录，只能用于观察幅相、回放与诊断，不能依据曲线形状猜距离再用于验证。旧静态 `empty` 记录也不能通过人为标注变成真实手指毫米实验。

离线选段和验证通过仅说明**同次记录内、留出静止区间**的表现。没有自动检测物理重新定位；如果旧记录没有明确阶段变化，仅有操作者补充动作与信号移动证据，报告会保留较弱的独立性依据，不能据此声称跨会话泛化。

## 6. 如何读验证报告

标定点用于拟合；验证点只用于检验，不能作为拟合节点。距离排序后，相位必须严格单调且相邻差异超过噪声门槛。同距离重复测量明显不同，可能是漂移、迟滞或姿态变化，软件会拒绝当前单值映射。

| 检查 | 默认门槛／行为 |
|---|---|
| 稳定窗口 | 至少 0.5 秒且至少 5 条处理记录，首尾覆盖、时间递增、无过渡或记录缺口；有样点身份时还核对样本连续性 |
| 相干占比 | 各点至少 0.8 |
| 静止相位 | 标准差不超过 3°，绝对漂移斜率不超过 1°/s |
| 静止幅度 | 标准差不超过 0.5 dB |
| 标定可分辨性 | 相邻位置相位差超过 3 倍联合噪声，并超过 0.5° 下限 |
| 独立验证 | 至少 2 个不同尺量距离、在标定范围内；所有区间不重叠，标定—验证间隔至少 1 秒且需动作／阶段证据 |
| 误差 | 估计距离 − 尺量真值；报告逐窗口误差、最大绝对误差和 RMSE；默认最大允许绝对误差 2 mm |
| 源实验 | 基线合格；活动采集未报错，或保存实验 complete、无错误且 EOB／RX stop／workers 全部确认 |

验证误差使用**每个独立静止窗口的相位中位数**，不是对每帧瞬时距离、所有动作速度或未来会话的精度保证。尺子分辨率、视差、测量基准、重复定位和手指姿态的不确定性没有被自动校准。

模型启用后仍逐点检查：同一 run、有限相位、相干、幅度和标定相位范围。幅度超过标定／验证窗口中位幅度范围的 ±3 dB 余量、相位越界或过渡段时不输出距离；实时数据过期、显示缺口、采集错误或已停止时暂停现场估算。范围外不外推，不用最后一个好值伪装当前测量。

发现验证失败时，保留失败报告，根据原因改善稳定性、几何定义、量程或实验设计，再做新的独立测量。不能把验证点改作标定后仍沿用原“独立”结论。

## 7. 派生分析文件

一次手指记录仍保存于 `Data/phase_runs/<run>/`。现场尺量窗口与动作存入 `finger_annotations.json`；初始距离、允许误差和引导／自由操作方式在首次确认时一起保存，导出参数也包含这些设置。每次分析创建独立版本：

```text
finger_research/<生成时间_唯一后缀>/
  analysis.json          完整窗口、标定模型、验证误差、质量与来源
  annotations.json       本次用于分析的人工区间
  windows.csv            每个窗口的数值及质量结果
  validation.csv         留出验证的真值、估计和误差
  estimated_series.csv   时间、距离、位移及无效点原因
  research_report.png    标定、误差、距离和位移图
  research_report.pdf    同内容报告
```

来源记录包括 run key、分析时保存序列完整前缀的字节数与 SHA-256、基线哈希、算法源码哈希、输入区间和模型绑定。运行中分析只使用当时已完整保存的 JSONL 前缀；报告不是对随后全部数据的自动复核。重新载入历史报告时核对该前缀与基线哈希，内容不一致则拒绝旧模型。停止后重新分析可覆盖完整保存序列并生成新版本。

## 8. 打包导出实验

在当前已保存实验或历史记录处点击“打包导出实验”，选择 ZIP 文件位置。默认不包含原始 IQ；需要重新做底层 DSP 时才勾选“包含原始 IQ（文件较大）”，`.cf32` 与 `.npz` 会显著增大体积。导出不会自动停止实验，先停止并等待保存。

```text
<用户命名>.zip
  README.txt              内容说明与分析边界
  parameters.json         保存的参数与实际配置；历史缺失字段保留未知
  bundle_manifest.json    来源 run、选项、排除 IQ 列表、逐文件大小及 SHA-256
  results/                原有 JSON／JSONL／CSV／XLSX、图表与日志
    finger_annotations.json        如该记录已有
    finger_research/<版本>/...     如该记录已有
    ... .cf32 / .npz               仅勾选原始 IQ 时
```

打包会为可支持的记录生成／刷新派生诊断图册，再收集结果；老师旧记录缺完整 IQ 时只包含已有图表，不补造新采集；核心 Excel 会从当前项目的 `Data/train/` 副本取入，并按老师历史记录的 SHA-256 核验。历史参数没有记录的字段不会用当前默认值填补。失败实验仍带原失败状态，ZIP 成功不表示实验成功。如果失败／不完整记录无法生成图册，仍打包可用证据并在完成提示与包内说明中列出缺失；完整实验的图册生成失败则中止导出，保留原目标文件。

压缩采用临时文件、源文件变化检查和压缩包校验后提交目标文件。请保留 `bundle_manifest.json`；它记录除自身以外的包内文件哈希，方便接收者核验。源 manifest、设备配置摘要和日志可能含设备身份或本机路径，包应先按需要检查再对外分享。

## 9. 筛选和比较多条已保存记录

在“实验档案与回放”按类型、状态和名称／传感器／key 关键词筛选；需要跨实验类型查找时点顶部“全部实验档案”或取消“仅当前实验”，再用复选框勾选 2–8 条同类型完成记录。当前行用于单条详情、回放或原实验导出，勾选集合用于比较，两者用途不同。老师原版历史记录单列，暂不并入新式比较。

扫频默认最早的所选记录为差值参考，可自行切换；phase 的报告排序参考不可切换。扫频显示均值与轮间样本标准差；参数齐全且一致时，按全部所选记录共同的 UHD TX／RX 载频回读与基带单音组合计算“目标 − 参考”差值，不插值。连续幅相以各自基线结束为时间零点，仅叠加相对自身基线的响应，不跨 run 相位相减，也不把一条记录的毫米模型套到另一条。

在比较窗口点“打包导出比较…”可选择 ZIP 保存位置，包含报告、参数表、CSV、重要 PNG／PDF、使用的源结果与哈希，不含原始 IQ。详细步骤、不可比原因与解释边界见 [已保存实验的筛选与比较](results_comparison.md)。

## 10. 本版本的验证范围

已有 2026-10-09 一次 90.94 秒空载静态连续幅相成功记录，可证明当时的静态采集和主动停止。它没有手指尺量标注，不能证明本轮毫米算法实际精度。合成数据、离线测试和界面检查验证软件规则与保存行为；真实材料扫频、手指动作、精度、迟滞、重复性、长时稳定性及端到端延迟仍需各自实验。
