# 已保存实验的筛选与比较

本功能用于只读比较已经保存的实验，不连接 USRP，也不改变任何源实验。比较报告说明哪些记录能叠加浏览、哪些满足定量差值条件；它不自动产生材料分类、跨会话绝对相位或毫米模型泛化结论。

本文随比较功能实施维护；正式安装与测试结果仍以 [桌面验收记录](acceptance_desktop.md) 为准。单次实验操作见 [实验工作流](experiment_workflows.md)，模块与数据设计见 [设计说明](design.md)。

## 1. 筛选、勾选和当前记录是三件事

在“实验结果与回放”用类型、状态和关键词缩小列表。类型为“材料逐点扫频”“手指位移”“历史连续幅相”“老师原版扫频”；开始时间按本机时区显示。关键词搜索名称、传感器或实验 key，状态可查完成、失败等记录。筛选或刷新后变得不可见的记录会清除勾选并提示，比较只使用当前可见的勾选项。

**比较使用复选框勾选的 2–8 条不同且同类型的完成态记录。**除完成／正常停止状态外，领域分析还检查错误为空、RF 停止证据完整。点击一行查看单条详情，不会自动改变比较集合；单条回放、研究分析与原实验 ZIP 导出继续针对当前行。失败记录可以查看与单独导出，但不加入本轮定量比较。

“手指位移”与“历史连续幅相”也分开比较，避免把未登记手指研究的旧 phase 自动解释为尺量实验。老师原版历史记录作为单独类型，保留原 Excel、图表和单次导出；不与新式扫频强行合并。本轮比较不会从老师表中推断缺失参数、真实频点精度或采集时间。

## 2. 比较流程

1. 进入“实验结果与回放”，先选实验类型，再按状态或关键词定位记录。
2. 勾选 2–8 条同类型的完成记录。名称相似不代表参数一致，需同时读报告中的参数与兼容性说明。
3. 点“比较所选实验”，打开“实验结果比较 · 只读分析”窗口。默认按可解析的 `started_utc` 选择最早记录；时间相同以输入顺序决定，全部缺失时也回退到输入顺序。扫频可在“差值参考实验”切换；phase／手指窗口的“报告排序参考”禁用，因为每条曲线使用自己的静止参考。扫频参考只是差值方向与显示基准，不自动成为“无物体”“空载”或校准参考。
4. 先读警告和“参数核对”，再看“比较图”“结果指标”和“数据表”中的叠加曲线及可用差值。没有定量差值时，查看缺失或不一致字段；不要通过重命名材料标签绕过限制。
5. 点“打包导出比较…”，选择 ZIP 保存位置。修改勾选集合或参考后重新生成比较，避免导出旧结果。

采集、保存、研究分析或其他导出尚未结束时，比较／对比导出暂不可执行；它们不会代替你停止实验。“清空勾选”只清除比较集合，不删除文件。

## 3. 材料扫频：叠加与差值分别判断

每条记录按保存频点汇总多轮幅度，显示**均值 ± 样本标准差**。样本标准差描述该 run 的轮间技术重复；不是均值置信区间，不包括重新摆放、独立样品或标定系统误差。只有一轮的点没有可估计的样本标准差，不能把它当作重复性为零。

定量差值定义为：

```text
差值(f) = 目标记录的平均幅度(f) − 参考记录的平均幅度(f)
```

差值只取**全部所选记录共有**的 **UHD TX 载频回读、RX 载频回读和设定基带单音**组合，不插值、不外推，不把不同频点强行配对。回读来自 manifest 的每点记录与 `point_number` 关联；CSV 请求载频另行保留。横轴为 TX 载频回读 + 设定单音；缺少回读时只可按请求载频 + 单音叠加并提示，禁止定量差值。UHD 回读不是独立仪器实测 LO，不能因此宣称频率经过外部标定。全部所选记录没有公共组合频点时不生成虚构差值；报告应保留各自可浏览的曲线和原因。幅度差单位为 dB，不是经标定的 S21，也不等于独立材料分类得分。差值误差棒为 `sqrt(SD_目标² + SD_参考²)`，仅是两组轮间 SD 的数值合成；不是均值差置信区间，也没有测得独立取放的差值误差。任一侧仅一轮时误差棒保持空缺。

核心设备身份、RF 采集参数和测量算法记录完整且一致时才允许定量差值。核对包括实际 TX／RX 采样率与增益、数字幅值、通道、天线选项、主时钟、FFT 点数、验证／测量单音周期、峰频容差、切频等待、设备与 FPGA 一致性以及估计器源码。缺失值表示未知，不能用当前 UI 默认值补填；不一致时仍可叠加浏览，但清楚提示不可定量相减。传感器名称空缺或机械位置未知会警告，但不单独阻断描述性的数字差；名称相同也不等于确认几何一致。参数可比性只覆盖软件保存的字段，无法自动核实接线、实际姿态、材料取放或环境变化。

比较不会自动把各 run 当成独立物理重复，亦不会合并成一个虚构大样本。研究者需结合当时的条件记录解释变化来源。

## 4. 连续幅相：各自参考下的响应形状

每条连续幅相记录有自己的初始基线。比较展示的是**各 run 相对自身参考的幅度和相位响应**，同时显示相干占比和质量摘要，可观察变化方向、幅度、漂移与阶段形状。横轴为 `t_s − baseline.end_s`，以各自静止基线结束时刻为零。

- 不把一个 run 的相对相位直接减另一个 run 的相对相位；本版 phase 不生成跨记录数值差图。
- 不把各自零相位解释为同一个跨会话物理相位。
- 不复用或合并任何 run 的毫米模型；同次尺量标定的绑定与验证边界保持。
- 不自动对齐物理手指动作或材料变化。基线结束对齐只是采集参考时点对齐，操作开始时刻和动作速度仍可能不同。

基线文件先按原采集工程的质量门槛检查。比较只取 `t_s > baseline.end_s` 的保存相对值，不再次归零或解缠。过渡动作和相干低于 0.8 的读数仍保留用于诊断，并显示计数／警告；它们不是通过手指毫米估算质量门槛的证明。缺失值和样本／时间缺口保持断线，样本重叠或倒退拒绝分析。

图形每条序列最多约 2,500 点，保留分桶极值与缺口；`phase_curves.csv` 保留所有基线后处理窗口。质量摘要包括基线幅度 SD、相位残差 SD／漂移、最低相干、低相干／缺失／缺口／过渡计数和全程峰峰值。**全程峰峰值含动作与漂移，不是静止噪声、毫米精度或重复性。**

每条曲线与参数仍保留来源 run。不同载频、单音、采样率、增益或几何条件的响应只能按报告中的限制解释，不能从形状相似推导相同距离、材料或因果关系。

## 5. 对比 ZIP 与单次实验 ZIP

| 导出方式 | 对象与内容 | 原始 IQ |
|---|---|---|
| 单次“打包导出实验…” | 当前行的参数、数据、诊断与研究报告；维持原操作 | 原有复选框可选，默认不选 |
| 对比 ZIP | 已生成的多记录报告、参数表、比较 CSV、重要 PNG／PDF、所用源结果及哈希 | 本版固定不包含 `.cf32`／`.npz` |

比较包需要保留参考 run、所有选用 run、报告时间、算法来源、兼容性原因与源文件 SHA-256。源结果按 run 隔离，避免同名 manifest 或 CSV 覆盖。导出不改原 manifest、IQ、幅相或历史研究结果；报告包是新的派生文件。

保存对话框取消不开始打包。对比包没有 IQ，不适合作为完整底层采集归档；若需要从原始信号重跑 DSP，应另用单次导出并选择 IQ。

对比包结构：

```text
<用户命名>.zip
  comparison.json         参考、所有来源、兼容性、结果与代码哈希
  parameters.json         各记录参数与逐项核对
  metrics.csv             每条记录的结果指标
  tables/*.csv            sweep_summary / sweep_measurements / sweep_difference
                          或 phase_summary / phase_curves 等实际比较数据
  figures/*.png           重要比较图
  figures/comparison_report.pdf
  sources/<run key>/...   实际解析的源结果、参数、基线，保持按 run 分开
  README.txt              内容和解释边界
  bundle_manifest.json    包内其余文件大小与 SHA-256
```

目的位置须在项目 `Data/` 之外。生成比较时绑定实际解析文件的大小／SHA-256，导出前再次核对；报告被改动、已过期、源文件或所绑定源码改变时要求重新比较；导出开始与提交目标之前均复核代码哈希。绘图在独立子进程完成，临时 ZIP 校验后再提交，失败保留原有目标文件。

参数核对中的设备／算法身份只呈现“参考／相同／不同／未知”等安全关系；包里的源文件保留原始来源内容，不等于全部已脱敏。

## 6. 如何解释结果

“可以显示”“可以做定量差值”“证明研究假设”是逐层不同的结论。叠加图只证明保存数据被正确呈现；软件参数一致且共频点存在，才能按定义作扫频幅度差；要归因于材料或手指，仍需可追溯条件、独立重复和相应对照。

扫频参考切换会改变差值方向或比较对象，不改变任何原记录；phase 不提供差值参考切换。连续幅相的各次参考保持独立。比较过程、离线测试或成功导出均不产生新的硬件实验，也不扩展此前静态真机或同 run 尺量验证范围。
