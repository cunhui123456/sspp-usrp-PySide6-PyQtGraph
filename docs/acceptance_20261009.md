随后加入初始化30秒上限、会话总时限、停止请求后的有界退出以及每运行 `web_console.log`。修复通过测试并安装后，重新连接设备的三次实际验收全部通过。初始化失败分支的自动超时由软件测试覆盖；本次成功运行未触发该超时，不声称人为重现了 C++ 挂起。
